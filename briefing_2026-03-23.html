1. Amenazas y Campañas Activas

Interlock Ransomware explota zero-day crítico en Cisco FMC para acceso root

Relevancia: CRÍTICA

El grupo Interlock Ransomware está explotando activamente CVE-2026-20131 (CVSS 10.0), una deserialización insegura en Cisco Secure Firewall Management Center que permite RCE sin autenticación. CISA emitió orden de parcheo de emergencia con plazo hasta el 22 de marzo para agencias federales. La explotación de dispositivos de seguridad perimetral como vector inicial representa una táctica de alto impacto orientada a maximizar el movimiento lateral en redes corporativas.

Hackers rusos vinculados a servicios de inteligencia comprometen cuentas de Signal y WhatsApp

Relevancia: CRÍTICA

El FBI y CISA alertaron sobre campañas de phishing activas de actores vinculados a inteligencia rusa que apuntan a comprometer cuentas en aplicaciones de mensajería cifrada como Signal y WhatsApp. Los objetivos son individuos de alto valor estratégico, con miles de cuentas ya comprometidas. La táctica refleja el interés de actores estatales rusos por interceptar comunicaciones de fuentes humanas fuera de canales gubernamentales monitorizados.

Ataque a cadena de suministro de Trivy se expande con CanisterWorm a 47 paquetes npm

Relevancia: CRÍTICA

El compromiso del escáner Trivy de Aqua Security fue explotado por el grupo TeamPCP para inyectar malware robador de credenciales en 75 tags de GitHub Actions y comprometer 47 paquetes npm mediante el gusano autopropagante CanisterWorm. El malware abusa de canisters ICP para persistencia y extrae secretos de pipelines CI/CD. La doble comprometida del mismo proyecto en menos de un mes indica un adversario con acceso persistente a la cadena de suministro del ecosistema DevSecOps.

Konni (APT norcoreano) distribuye EndRAT mediante KakaoTalk como vector lateral

Relevancia: ALTA

El grupo Konni, vinculado a Corea del Norte, está usando spear-phishing para comprometer dispositivos y luego abusar de la aplicación de escritorio KakaoTalk de la víctima para propagar payloads maliciosos a contactos de confianza. La técnica convierte las comunicaciones legítimas del objetivo en un vector de distribución secundario, dificultando la detección. El uso de plataformas de mensajería locales sugiere operaciones dirigidas específicamente a objetivos surcoreanos o de la diáspora coreana.

DRILLAPP backdoor apunta a entidades ucranianas abusando del depurador de Microsoft Edge

Relevancia: ALTA

Una campaña observada en febrero de 2026 despliega el backdoor DRILLAPP contra organizaciones ucranianas, con solapamientos atribuidos a Laundry Bear (UAC-0190/Void Blizzard), actor vinculado a Rusia. La operación forma parte del patrón continuo de ciberespionaje ruso contra infraestructura de defensa ucraniana.

2. Vulnerabilidades Destacadas

CVE-2026-20131 — Cisco Secure FMC: RCE sin autenticación (CVSS 10.0) explotado por ransomware

Relevancia: CRÍTICA

Deserialización insegura de flujos Java en Cisco Firewall Management Center permite a un atacante remoto no autenticado ejecutar código con privilegios root. Bajo explotación activa confirmada por el grupo Interlock Ransomware según Amazon Threat Intelligence. CISA incluyó en KEV con plazo de parcheo de emergencia; dispositivos expuestos a internet deben considerarse comprometidos hasta evidencia contraria.

CVE-2025-32975 — Quest KACE SMA: explotación activa confirmada (CVSS 10.0)

Relevancia: CRÍTICA

Arctic Wolf detectó actividad maliciosa desde la semana del 9 de marzo de 2026 en entornos de clientes con sistemas Quest KACE SMA sin parchear expuestos a internet, consistente con la explotación de esta vulnerabilidad de severidad máxima. KACE SMA se usa ampliamente para gestión de endpoints en entornos empresariales, lo que amplifica el radio de impacto potencial. La exposición pública del sistema de gestión convierte este vector en crítico para operaciones de movimiento lateral masivo.

DarkSword iOS Exploit Kit: 6 vulnerabilidades incluyendo 3 zero-days para toma de control total

Relevancia: CRÍTICA

El kit de explotación DarkSword, activo desde noviembre de 2025, combina 6 vulnerabilidades de iOS —incluyendo 3 zero-days— para lograr compromiso total del dispositivo. Según Google GTIG, iVerify y Lookout, múltiples vendors de spyware comercial y actores de estado lo han utilizado activamente. CISA ordenó parcheo urgente a agencias federales; los ataques se vinculan tanto a ciberespionaje como a robo de datos de alto valor.

Relevancia: CRÍTICA

Fallo de autenticación ausente combinado con inyección de código en la plataforma de orquestación de IA Langflow permite ejecución remota de código sin credenciales. 3. Artículos Recomendados

Botnets IoT AISURU, Kimwolf, JackSkid y Mossad desmantelados tras ataques DDoS de 31.4 Tbps

Relevancia: ALTA

Una operación coordinada entre DoJ, Canadá y Alemania desarticuló la infraestructura C2 de cuatro botnets IoT que comprometieron más de 3 millones de dispositivos —routers y cámaras web— y fueron responsables de ataques DDoS récord de 31.4 Tbps. La escala de estos ataques indica que actores con acceso a estas redes pueden neutralizar prácticamente cualquier objetivo en internet. La operación es relevante para organizaciones que operan infraestructura crítica expuesta a campañas volumétricas.

54 herramientas EDR Killer abusan de 35 drivers firmados vulnerables mediante BYOVD

Relevancia: ALTA

Un análisis reveló que 54 programas de tipo EDR killer activos —presentes en intrusiones de ransomware— explotan la técnica Bring Your Own Vulnerable Driver (BYOVD) abusando de 35 drivers firmados legítimamente. La técnica permite neutralizar soluciones de seguridad antes del despliegue del ransomware, eludiendo controles de integridad del kernel. La proliferación de estas herramientas indica una industrialización del bypass de EDR como paso estándar en ataques de ransomware.

Fallos en IA: Amazon Bedrock, LangSmith y SGLang permiten exfiltración de datos y RCE vía DNS

Relevancia: ALTA

BeyondTrust describió un nuevo método de exfiltración de datos en entornos de ejecución de código IA mediante consultas DNS, afectando a Amazon Bedrock AgentCore, LangSmith y SGLang. El sandbox de Bedrock AgentCore permite consultas DNS salientes que habilitan shells interactivos para un atacante. Este vector ilustra la superficie de ataque emergente de los entornos de agentes IA en producción, donde los controles de red tradicionales resultan insuficientes.

GlassWorm: tokens GitHub robados usados para inyectar malware en cientos de repositorios Python

Relevancia: ALTA

La campaña GlassWorm utiliza tokens GitHub comprometidos para realizar force-push de código ofuscado malicioso en repositorios Python legítimos, incluyendo proyectos Django, código ML y paquetes PyPI. El malware se añade a ficheros de entrada como setup.py, afectando a cualquier usuario que instale o ejecute el código. El ataque supone una amenaza directa para organizaciones que consumen dependencias Python sin verificación de integridad en sus pipelines de desarrollo.

LeakNet Ransomware adopta ClickFix para acceso inicial mediante sitios web comprometidos

Relevancia: ALTA

El grupo LeakNet Ransomware ha incorporado la táctica ClickFix —engañar a usuarios para ejecutar comandos maliciosos manualmente a través de sitios web comprometidos— como método de acceso inicial, sustituyendo el uso de credenciales robadas tradicionales. El loader en memoria basado en Deno dificulta la detección forense al no escribir en disco. La adopción de ingeniería social avanzada combinada con técnicas de evasión indica una maduración operativa de este grupo de ransomware.
